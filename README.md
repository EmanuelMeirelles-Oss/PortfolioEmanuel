# 🚀 Portfólio Profissional — Emanuel Meirelles

Portfólio web de alta conversão para **Emanuel Meirelles — Desenvolvedor Web**, construído com tecnologias de ponta, design interativo, animações fluidas e otimização para dispositivos móveis.

---

## ⚡ Tecnologias Utilizadas

- **Core**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
- **Estilização**: [Tailwind CSS](https://tailwindcss.com/)
- **Animações e Efeitos**: [Framer Motion](https://www.framer.com/motion/), Canvas 2D Mesh Distort ([WarpText](file:///d:/portfolio_EmanuelMeirelles/src/components/WarpText.tsx)), [ClickSpark](file:///d:/portfolio_EmanuelMeirelles/src/components/ClickSpark.tsx) (partículas brancas de clique), [Magnet](file:///d:/portfolio_EmanuelMeirelles/src/components/Magnet.tsx) (atração de avatar)
- **Ícones**: [Lucide React](https://lucide.dev/)

## 🛠️ Seções do Site

- **Hero Header**: Título interativo *"EU CRIO SITES"* com efeito `WarpText` responsivo ao cursor do mouse.
- **Avatar Magnético**: Avatar 3D transparente de Emanuel Meirelles com atração magnética ([Magnet](file:///d:/portfolio_EmanuelMeirelles/src/components/Magnet.tsx)).
- **Carrossel de Trabalhos Reais**: Slider infinito com capturas reais dos 5 sites publicados.
- **Sobre Mim**: Apresentação profissional em 1ª pessoa com revelação caractere por caractere via scroll.
- **Serviços Numerados (`01` a `05`)**: Landing Pages, Sites Institucionais, Lojas Virtuais, Sistemas Web e SEO & Performance.
- **Galeria de Projetos**: Cards com capturas reais dos sites, tags e links diretos para acesso no ar.
- **Modal de Contato**: Acesso rápido ao WhatsApp, E-mail e LinkedIn.
- **ClickSpark Global**: Efeito de partícula ao clicar em qualquer elemento da página.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/EmanuelMeirelles-Oss/PortfolioEmanuel.git
   cd PortfolioEmanuel
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Para compilar a versão de produção:
   ```bash
   npm run build
   ```

## 🌐 Deploy Automático na Vercel

Este repositório está pronto para deploy automático na **Vercel**:
- Conecte este repositório `EmanuelMeirelles-Oss/PortfolioEmanuel` na Vercel.
- O build command é `npm run build` e a pasta de saída é `dist`.
- Qualquer novo `git push` na branch `main` atualizará o site em tempo real automaticamente na Vercel!
